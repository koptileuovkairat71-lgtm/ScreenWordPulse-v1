# ScreenWordPulse — этап 1.0 (сборка APK через GitHub Actions)

Нет Android Studio? Не нужно. APK собирается в облаке.

## Как получить APK за 5 минут (с Windows 7, только браузер)
1. Зайди на https://github.com/new — создай репозиторий, например `ScreenWordPulse` (Public).
2. На странице репозитория нажми `uploading an existing file` / `Add file -> Upload files`.
3. Загрузи ВСЕ файлы из этого архива (сохраняя папки: `app/`, `core/`, `.github/`, `gradle/` и т.д.). Можно загрузить ZIP целиком через `git`? Проще: перетащить папки по очереди. Важно: папка `.github` должна попасть тоже — иначе сборка не запустится.
   - Альтернатива без ручной загрузки: если есть git — `git init, git add ., git commit, git push`.
4. Открой вкладку `Actions` в репозитории -> выбери `Build APK (Debug)` -> дождись зелёной галочки (3-7 минут).
5. Открой завершённый запуск -> внизу `Artifacts` -> скачай `ScreenWordPulse-debug-apk` -> внутри `app-debug.apk`.
6. Перекинь APK на телефон (USB / Telegram / WhatsApp себе) и установи. При установке разреши "Установка из неизвестных источников" для этого источника.

## Что внутри сборки
- Workflow сам скачивает `rus/kaz/eng.traineddata` из tessdata_fast — тебе не нужно ничего скачивать.
- Собирается `assembleDebug` (debug-подпись, ставится на любой телефон Android 8+).
- Заодно гоняется `:core:selfCheck`.

## Первый запуск на телефоне
Разреши камеру -> наведи на лист -> веди сверху вниз медленно. Зелёный = зафиксировано, жёлтый = задержись, красный + вибрация = пропуск, вернись выше.
Кнопки внизу: Следующий лист / Переснять лист / Вспышка / Поиск / Скопировать для ИИ / Новая сессия.

## Если Actions красный
Открой лог шага `Build Debug APK` и пришли мне текст ошибки — поправлю код и пришлю исправленный файл.
